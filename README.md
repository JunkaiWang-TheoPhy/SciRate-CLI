## Introduction

SciRate CLI is a workspace for developing command-line tooling for [SciRate](https://scirate.com). The repository currently contains project documentation and a starting structure; executable commands have not been implemented.

## Next Steps

Confirm the available integration interfaces, define the first supported commands, and document their input and output formats before implementation.

## Structure

- `docs/`: interface research and command design
- `src/`: implementation
- `assets/`: visual material
