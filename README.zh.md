## 引言

SciRate CLI 是为 [SciRate](https://scirate.com) 开发命令行工具的工作区。当前仓库包含项目文档与起始目录，尚未实现可执行命令。

## 下一步

先核实可用的集成接口，确定首批支持的命令，并记录其输入与输出格式，再开始实现。

## 目录

- `docs/`：接口调研与命令设计
- `src/`：实现代码
- `assets/`：视觉资料
