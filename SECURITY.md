# Security

Do not attach credentials, session HTML, browser receipts, or local caches to public issues. Report vulnerabilities privately to the repository owner or through GitHub private vulnerability reporting.

The bridge executes JavaScript in an existing SciRate session. It does not read cookie databases or export cookies. Browser Apple Events permissions are broader than this tool; use only on a trusted machine. Read-only MCP tools can still expose private page content to their caller.

Write commands require explicit intent, a signed-in session and CSRF token. A pending ticket or HTTP 200 does not establish acceptance. Never automatically retry uncertain writes. Receipts disappear on navigation and belong to the original tab. Browser requests time out after 25 seconds; a timeout does not prove rejection by the server.

HTTP and imported HTML are capped at 8 MB; HTTP requests time out after 25 seconds. Cache files use owner-only permissions. Administrators and processes under the same user can still read them. No anti-bot bypass or unattended login is provided.
