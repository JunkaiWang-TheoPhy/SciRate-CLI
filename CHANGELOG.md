# Changelog

## 0.3.0 - 2026-09-29

Initial packaged beta, migrated from the local prototype.

- JSON CLI for arXiv metadata, SciRate feeds, community data and paginated scites.
- Saved-page import and macOS Chrome/Safari bridge.
- Explicit scite, subscription, comment and reply actions with asynchronous receipts.
- Six read-only stdio MCP tools.
- Atomic owner-only cache writes, malformed-cache recovery, version reporting and browser request timeout.
- Bilingual documentation, source ledger, regression tests, CI, wheel and source distribution.

Limits: no stable official SciRate API, possible Cloudflare blocks, real account write acceptance requires live verification. No TUI or comment edit/delete commands.
